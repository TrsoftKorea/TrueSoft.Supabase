# 탈퇴 취소 — 토큰 방식

유예 기간이 지나 이미 탈퇴가 완료된 경우, 토큰을 이용해 계정을 복구할 수 있습니다. 서버에서 토큰을 발급받아 이메일 등으로 전달하고, 플레이어가 해당 토큰으로 취소를 완료하는 방식입니다. [Edge Function 배포](/guide/start/database-setup#edge-function-deploy)가 선행되어야 합니다.
