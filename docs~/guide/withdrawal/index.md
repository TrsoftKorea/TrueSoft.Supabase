# 탈퇴 처리

계정 탈퇴를 예약·취소하거나 바로 처리하는 기능입니다.

## 예약 탈퇴와 즉시 탈퇴 {#kinds}

탈퇴는 두 가지입니다. 기본은 **유예 기간을 둔 예약 탈퇴**로, 유예 중에는 취소할 수 있고 취소 없이 유예가 지나면 계정이 삭제됩니다. 바로 지워야 하면 [즉시 탈퇴](/guide/withdrawal/delete-now)를 씁니다.

유예 기간은 운영 콘솔 **설정 › 플레이어**에서 프로젝트마다 정하고 1~90일입니다. 고객센터 웹의 계정 삭제도 같은 기간을 씁니다. 삭제 시각은 유예가 끝난 **다음 자정**입니다. 예를 들어 10월 27일 오후 3시에 7일 유예로 신청하면 11월 4일 0시에 삭제됩니다. 자정을 어느 나라 시간으로 셀지는 운영 콘솔 **설정 › 일반**에서 프로젝트마다 정합니다.

## 처리 흐름

1. **탈퇴 신청** — `RequestWithdrawalAsync()`로 유예를 예약합니다. 성공하면 **즉시 로그아웃**되어 본편에 들어갈 수 없습니다. Apple로 로그인한 계정은 이때 [Apple 연결도 끊깁니다](/guide/social/apple/#revoke).
2. **유예 중 재로그인** — 예약된 계정으로 다시 로그인하면 SDK가 **게이트**에서 세션을 정리한 뒤, 로그인을 `WithdrawalGateBlocked` 실패로 반환합니다. 이때 로그인 결과에 삭제 예정 시각 `WithdrawnAt`과 취소 토큰 `WithdrawalCancelToken`이 함께 실려 옵니다.
3. **탈퇴 취소** — 그 값으로 남은 시간을 보여주고 `RedeemWithdrawalCancelAsync`로 예약을 해제합니다. 삭제 시각인 자정 전까지 취소할 수 있습니다.
4. **유예 만료** — 서버가 자정 직후에 계정을 삭제합니다. 완료된 탈퇴는 되돌릴 수 없고, 같은 소셜 계정으로 다시 로그인하면 새 계정이 만들어집니다.

::: info
취소 토큰은 게이트가 내부적으로 발급·저장하므로 게임이 직접 발급할 필요가 없습니다. 취소는 `RedeemWithdrawalCancelAsync()` 한 번으로 처리됩니다.
:::

::: details 자정과 삭제 사이에 로그인하면
서버가 삭제를 끝내기 전 몇 초 사이, 또는 서버 정리가 실패했을 때 로그인하면 그 로그인 안에서 계정을 지우고 새 계정을 만듭니다. 구글·애플은 방금 받은 로그인 토큰을 다시 써서 로그인 창이 한 번만 뜹니다. 구글은 서버가 그 토큰을 다시 받지 않으면 로그인 창을 한 번 더 띄웁니다.
:::

## 스토어의 계정 삭제 요청 주소 {#store-delete-url}

Google Play는 계정을 만드는 앱에 앱을 다시 받지 않고도 삭제를 요청할 수 있는 웹 주소를 요구합니다. 고객센터 웹의 계정 삭제 화면 주소를 Play Console **앱 콘텐츠 › 데이터 보안**에 적습니다.

```text
https://truebase-support.pages.dev/?p=<프로젝트 ref>&view=delete
```

이 화면은 스토어 이름으로 운영 콘솔 프로젝트 이름을 보입니다. 구글·애플로 로그인한 플레이어는 여기서 탈퇴를 예약하고 취소합니다. 유예는 게임 안 탈퇴와 같은 기간이고, 그 사이 게임에 접속하면 [탈퇴 취소](/guide/withdrawal/cancel) 흐름이 그대로 돕니다. 게스트 계정은 웹에서 본인을 확인할 수 없어 게임 설정에서 지우도록 안내합니다. 운영 콘솔 **설정 › 플레이어**에서 정한 기간(기본 365일) 동안 접속이 없는 게스트는 서버가 자동으로 지웁니다. 구글·애플이 연결됐거나 결제 기록이 있는 게스트는 지우지 않습니다. 지우는 데이터와 보관하는 데이터도 이 화면에 나옵니다.

::: info
로그인 단추는 운영 콘솔 **서비스 연결**의 Google 로그인·Sign in with Apple 값이 있을 때만 보입니다. 둘 다 없거나 **설정 › 플레이어**에서 웹 삭제를 끈 프로젝트는 게임 설정에서 지우라는 안내만 보입니다. 플레이나누를 함께 쓰는 게임은 웹 삭제를 끕니다. 웹은 Supabase 쪽 계정만 바꿔 플레이나누 계정과 삭제·취소가 갈립니다.
:::
