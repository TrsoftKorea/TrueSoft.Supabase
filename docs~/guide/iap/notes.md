# 사용 시 알아둘 점

- **초기화 시점**: `CreateIAPAsync`는 로그인 완료 후에 호출합니다. 자동 로그인 경로에서도 동일합니다. 초기화 도중 스토어에 남아있는 미처리 주문이 있으면 [구매 처리 흐름](/guide/iap/usage#purchase-flow)이 곧바로 재시작되는데, 이때 세션이 없으면 서버 검증이 실패해 불필요한 재시도가 한 번 낍니다.
- **지원 범위**: 소모품만 지원합니다. 비소모품·구독은 아직 지원하지 않습니다.
- **정리**: `OnDestroy`에서 `Dispose()`를 호출해 이벤트 핸들러를 정리합니다.
- **계정을 바꿀 때**: 미처리 주문은 스토어 계정에 남아 있어, 다음에 로그인한 게임 계정으로 검증·지급됩니다. 한 기기에서 계정을 갈아 쓰는 구조라면 로그아웃 전에 `Dispose()`로 파사드를 끊고, 다시 로그인한 뒤 새로 만드세요.
