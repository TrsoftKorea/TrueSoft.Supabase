# 채팅

플레이어끼리 대화하는 기능입니다. 채널은 어드민(Retool)에서 만들고, 게임은 구독해서 읽고 보내기만 합니다.

## 채널 종류 {#kinds}

| 종류 | 대화 범위 | 쓰임새 |
|------|-----------|--------|
| 전체 | 모든 플레이어가 같은 방 | 외치기 |
| 서버 | 같은 서버에 있는 플레이어끼리 | 서버 채팅 |

설치하면 `shout`(외치기)과 `server`(서버 채팅) 두 채널이 기본으로 들어 있습니다. 운영자가 이름·최대 글자 수·보관 기간을 바꾸거나 채널을 더 만들 수 있습니다.

대화가 갈리는 기준은 **서버가 정합니다.** 게임이 "어느 서버의 대화를 달라"고 지정할 수 없으므로, 다른 서버 대화를 들여다볼 방법이 없습니다.

## 새 메시지 받기 {#subscribe}

채팅창을 열 때 [구독](/guide/chat/subscribe)하고, 닫을 때 해제합니다. 구독하는 동안 SDK가 주기적으로 새 메시지를 확인해 콜백으로 넘깁니다.

```csharp
private ChatSubscription _sub;

void OpenChatWindow()
{
    var r = Supabase.SubscribeChat(new[] { "shout", "server" }, OnMessages);
    if (r.IsSuccess) _sub = r.Data;
}

void CloseChatWindow()
{
    _sub?.Dispose();
    _sub = null;
}
```

채널을 여러 개 구독해도 **서버에는 한 번만 요청**합니다. 조회 간격은 대화가 오갈 때 짧아지고 조용하면 길어집니다.

::: warning 구독은 반드시 해제하세요
`Dispose`를 부르지 않으면 채팅창을 닫아도 조회가 계속 돕니다. 씬을 떠날 때도 정리되도록 `OnDestroy`에 넣어 두세요.
:::

## 도배 제한과 발언 차단 {#moderation}

두 가지가 따로 있습니다.

**발언 간격**은 채널 설정입니다. 기본값 0이라 제한이 없고, 운영자가 값을 넣으면 그때부터 같은 사람의 연속 발화를 막습니다.

**발언 차단**은 특정 플레이어를 기간을 정해 막는 것입니다. 운영자가 Retool에서 지정하며, 전 채널 또는 특정 채널만 고를 수 있습니다.

둘 다 서버가 판정하므로 게임이 우회할 수 없습니다.

## 메서드

| 메서드 | 설명 |
|--------|------|
| [`GetChatChannelsAsync`](/guide/chat/channels) | 사용 가능한 채널 목록 |
| [`SubscribeChat`](/guide/chat/subscribe) | 채널 구독 · 새 메시지 수신 |
| [`SendChatAsync`](/guide/chat/send) | 메시지 발송 |

채널 생성·설정, 대화 삭제, 발언 차단은 어드민 전용이라 SDK에 없습니다.

::: info 지운 대화가 반영되는 시점
운영자가 지운 발언은 화면에 이미 떠 있는 동안에는 그대로 남고, 유저가 채팅창을 다시 열 때 삭제 표시로 바뀝니다.
:::
