# 매치 결과

대전·협동 판의 결과를 기록하고 읽는 기능입니다. 보상은 지급하지 않습니다. 2인 판은 참가자 양쪽이 신고한 결과를 서로 맞춰 보고 확인 단계를 매깁니다. 봇을 상대했거나 혼자 한 판은 [상대 없는 판 기록](/guide/match-result/report-solo)으로 남깁니다. 쌓인 기록은 [전적 요약](/guide/match-result/stats)과 [최근 전적](/guide/match-result/history)으로 읽습니다.

## 교차검증 흐름 {#cross-check}

두 참가자는 매치가 끝나면 각자 자기 쪽 결과를 신고합니다. 먼저 도착한 신고는 대기 상태로 남고, 상대 신고가 도착하면 서버가 그 자리에서 맞춰 봅니다.

1. 상대가 나를 상대로 지목했는지 확인합니다 — 서로 다른 매치를 가리키고 있으면 무효가 됩니다.
2. 승패가 게임 코드의 확인 방식과 맞는지 확인합니다. 경쟁 매치는 승패가 서로 반대여야 하고, 협동 매치는 결과가 같아야 합니다.
3. 두 조건을 모두 통과하면 양쪽 기록이 `Verified`가 됩니다.

같은 세션을 다시 신고해도 기록이 늘지 않습니다. 다시 신고할 때 상대나 게임 코드를 처음과 다르게 보내면 `MatchResultMismatch`로 실패하고 처음 신고가 그대로 남습니다.

## 기록의 확인 단계 {#trust}

모든 기록은 어디까지 확인됐는지에 따라 넷으로 나뉩니다. 조회 결과도 이 단계별로 나눠 오므로, 어디까지 믿을지는 게임이 고릅니다.

| 단계 | 뜻 | 계정&nbsp;하나로&nbsp;조작 |
|------|-----|-----------|
| `Verified` | 상대 신고와 맞춰 봤습니다 | 불가 |
| `Pending` | 상대가 아직 신고하지 않았습니다 | 가능 |
| `Solo` | 상대 없는 판입니다 | 가능 |
| `Mismatch` | 상대 신고와 맞지 않아 무효입니다. 요약에서는 빠집니다 | 불가 |

`Verified`도 한 사람이 계정 두 개로 서로를 지목하면 만들 수 있습니다. 게임이 이 기록으로 재화를 준다면 운영 콘솔에서 같은 상대와 반복되는 기록을 살펴보세요. 판마다 함께 보내는 점수는 단계와 상관없이 각자 보낸 값이라 상대와 맞춰 보지 않습니다.

## 게임 코드는 운영 콘솔에 등록합니다 {#game-code}

게임 코드와 그 확인 방식(경쟁·협동)은 운영 콘솔의 매치 기록 화면에서 등록합니다. 등록되지 않은 게임 코드는 2인 판과 상대 없는 판 모두 받지 않습니다. 쌓인 기록은 같은 화면과 플레이어 상세에서 보며 고객 문의에 답할 때 씁니다.

## 메서드

| 메서드 | 설명 |
|--------|------|
| [`ReportMatchResultAsync`](/guide/match-result/report) | 본인이 겪은 2인 판 결과 신고 |
| [`ReportSoloMatchResultAsync`](/guide/match-result/report-solo) | 상대 없는 판 기록 |
| [`GetMatchStatsAsync`](/guide/match-result/stats) | 내 승·패 수와 점수 최댓값·최솟값 |
| [`GetMatchHistoryAsync`](/guide/match-result/history) | 내 기록을 최근 순으로 |

::: info 랭킹·시즌은 리더보드로
다른 플레이어와 순위를 겨루거나 시즌마다 초기화하는 기록은 [리더보드](/guide/leaderboard/)가 맡습니다.
:::
