# 매치 결과

2인 매치의 승패에 따라 영구 재화를 지급하는 기능입니다. 클라이언트가 신고하는 결과를 그대로 믿지 않고, 참가자 양쪽이 신고한 결과가 서로 맞을 때만 지급합니다. 게임은 [결과 신고](/guide/match-result/report)만 합니다.

## 교차검증 흐름 {#cross-check}

두 참가자는 매치가 끝나면 각자 자기 쪽 결과를 신고합니다. 먼저 도착한 신고는 대기 상태로 남고, 상대 신고가 도착하면 서버가 그 자리에서 맞춰 봅니다.

1. 상대가 나를 상대로 지목했는지 확인합니다 — 서로 다른 매치를 가리키고 있으면 지급하지 않습니다.
2. 승패가 게임 코드의 검증 정책과 맞는지 확인합니다. 경쟁 매치는 승패가 서로 반대여야 하고, 협동 매치는 결과가 같아야 합니다.
3. 두 조건을 모두 통과해야 승리 쪽에 보상 우편이 갑니다.

같은 세션을 다시 신고해도 중복 지급되지 않습니다.

## 보상은 게임 코드 단위로 설정합니다 {#reward-config}

승리 보상 아이템·검증 정책은 game_code별로 Retool 어드민에 등록합니다. 클라이언트는 승패 여부만 보낼 뿐 지급 액수를 정하지 않으므로, 신고 값을 조작해도 서버가 정한 것만 나갑니다.

| 메서드 | 설명 |
|--------|------|
| [`ReportMatchResultAsync`](/guide/match-result/report) | 본인이 겪은 매치 결과 신고 |
