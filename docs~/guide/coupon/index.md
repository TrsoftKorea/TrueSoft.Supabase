# 쿠폰

유저가 코드를 입력하면 보상을 받는 기능입니다. 쿠폰은 Retool 어드민에서 만들고, 게임은 [코드 사용](/guide/coupon/redeem)만 합니다.

## 두 가지 쿠폰 {#kinds}

| 종류 | 코드 | 사용 제한 |
|------|------|-----------|
| 일반 | 발급 수량만큼 랜덤 생성. `CODEDRH`·`CODEKFT` | 코드 1개당 1회 |
| 키워드 | 운영자가 직접 지정. `THANKYOU` | 최대 횟수까지 여러 명, 한 플레이어는 1회 |

일반 쿠폰은 코드 하나가 곧 선물 하나입니다. 같은 캠페인의 다른 코드를 여러 장 받았다면 각각 쓸 수 있고, 누가 어떤 코드를 썼는지 코드 단위로 남습니다.

키워드 쿠폰은 하나의 코드를 여러 사람이 씁니다. 최대 횟수를 비우면 무제한입니다.

## 보상은 우편으로 옵니다 {#reward-by-mail}

쿠폰 사용 응답에는 보상이 들어 있지 않습니다. 서버가 [우편](/guide/mailbox/)을 만들어 넣으므로, 게임은 사용에 성공한 뒤 우편함을 새로 조회하면 됩니다. 실제 지급은 기존 [아이템 핸들러](/guide/mailbox/item-handler)를 그대로 탑니다.

```csharp
var result = await Supabase.RedeemCouponAsync(input.text);
if (result.IsSuccess)
{
    ShowToast("쿠폰을 사용했습니다. 우편함을 확인하세요.");
    await RefreshMailboxAsync();
}
```

## 메서드

| 메서드 | 설명 |
|--------|------|
| [`RedeemCouponAsync`](/guide/coupon/redeem) | 쿠폰 코드 사용 |

쿠폰 생성·수정·삭제와 코드 발급은 어드민 전용이라 SDK에 없습니다.

::: info 유효기간은 두 가지입니다
쿠폰의 만료 시각이 지나면 코드를 더 쓸 수 없습니다. 지급된 우편에는 그와 별개로 수령 기한이 있어, 쿠폰이 만료돼도 이미 받은 우편은 그 기한까지 수령할 수 있습니다.
:::
