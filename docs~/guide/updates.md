# 업데이트 내역

SDK 판마다 게임에 달라지는 점입니다. 판을 올리는 방법은 [설치](/guide/start/install)를 참고하세요.

## 0.3.2 {#v0-3-2}

2026-11-23

- 스토어(Google Play·App Store)에 연결하지 못하면 `CreateIAPAsync`가 제한 시간을 기다리지 않고 바로 `SupabaseReason.IapStoreConnectFailed` 실패로 알립니다. 전에는 제한 시간이 지난 뒤 `IapInitTimeout`으로 알렸습니다.
- 결제 준비가 끝난 뒤 스토어 연결이 끊기면 `Purchase`가 `false`를 돌려줍니다. `CreateIAPAsync`를 다시 부르면 다시 연결합니다. [사용법](/guide/iap/usage)을 참고하세요.
- Unity IAP 5.2 이상에서 에디터 플레이 때마다 뜨던 스토어 연결 경고 두 줄이 더 뜨지 않습니다.

## 0.3.1 {#v0-3-1}

2026-11-23

- 우편에 처리기가 실패한 보상과 서버가 데이터 필드에 더한 보상이 함께 있을 때, 서버가 더한 값이 게임 안의 값에 빠지던 문제를 고쳤습니다. 빠진 채로 저장하면 서버가 더한 값이 덮여 사라졌습니다.

## 0.3.0 {#v0-3-0}

2026-11-20

::: warning 게임 코드를 고쳐야 합니다
`SupabaseSettings`의 `duplicateSessionPollSeconds`·`duplicateSessionActionCheckCooldownSeconds`를 지웠습니다. 게임 코드에서 이 값을 쓰고 있었다면 그 줄을 지우세요. 접속 확인은 60초로 고정되고, 중복 로그인 감지는 늘 켜져 있습니다.
:::

- 다른 기기에서 같은 계정으로 로그인하면, 옛 기기의 다음 요청을 서버가 그 자리에서 거절합니다. 앱으로 돌아올 때도 바로 확인합니다. [중복 로그인 감지](/guide/auth/duplicate-login)를 참고하세요.
- 세이브 저장이 성공하면 접속 확인을 60초 미룹니다. 저장이 이어지는 동안에는 접속 확인 요청이 나가지 않습니다.
- 다른 기기가 쓰고 있는 계정을 자동 로그인으로 되살리면 `SupabaseReason.DuplicateLogin` 실패로 알립니다.
- 우편 보상 키가 숫자 데이터 필드 이름과 같으면, 받을 때 서버가 그 필드에 더합니다. 처리기는 더하기만으로 안 되는 보상에만 등록하면 됩니다. [아이템 핸들러 등록](/guide/mailbox/item-handler)을 참고하세요.
- 세이브 변경을 확인할 때 쓰는 메모리를 줄였습니다.
- 가이드의 함수 페이지마다 실사용 예시를 넣었습니다.

## 0.2.1 {#v0-2-1}

2026-11-19

- 서버가 SDK보다 새 친구 관계·매치 로비 상태를 보내면 `Unknown`으로 읽습니다. 전에는 다른 상태로 잘못 읽었습니다.
- 차단된 계정이 구글·애플 연결을 누르면 실패 결과에 차단 기간과 사유가 함께 옵니다.
- 처리기가 등록되지 않은 우편 보상을 받으면 `SupabaseReason.MailItemHandlerMissing`으로 실패합니다.

## 0.2.0 {#v0-2-0}

2026-11-16

::: warning 클래스 생성기 설정을 다시 해야 합니다
유저 데이터·원격 설정 클래스 생성기가 Secret key 대신 운영 콘솔에서 발급한 생성기 열쇠를 씁니다. 생성기 창에 생성기 열쇠를 넣으면 예전에 저장해 둔 Secret key 는 함께 지워집니다.
:::
