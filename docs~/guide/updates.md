# 업데이트 내역

SDK 판마다 게임에 달라지는 점입니다. 판을 올리는 방법은 [설치](/guide/start/install)를 참고하세요.

## 0.3.3 {#v0-3-3}

2026-11-23

- **연결이 끊긴 뒤 구매 실패 알림** — 결제 준비가 끝난 뒤 스토어 연결이 끊겨도 `Purchase`가 결제를 시도하고, 실패는 `onFailed`로 알립니다. 0.3.2에서는 `false`만 돌려주고 `onFailed`가 불리지 않았습니다.

## 0.3.2 {#v0-3-2}

2026-11-23

- **Google Play 연결 실패 바로 알림** — Google Play에 연결하지 못하면 `CreateIAPAsync`가 제한 시간을 기다리지 않고 바로 `SupabaseReason.IapStoreConnectFailed` 실패로 알립니다. 전에는 제한 시간이 지난 뒤 `IapInitTimeout`으로 알렸습니다.
- **연결이 끊긴 뒤 구매 막음** — 결제 준비가 끝난 뒤 스토어 연결이 끊기면 `Purchase`가 `false`를 돌려줍니다. 0.3.3에서 되돌렸습니다.
- **스토어 연결 경고 제거** — 에디터·개발 빌드에서 결제를 준비할 때마다 뜨던 스토어 연결 경고(Unity IAP 5.2 이상은 두 줄)가 더 뜨지 않습니다.

## 0.3.1 {#v0-3-1}

2026-11-23

- **우편 서버 지급분 누락 수정** — 우편에 처리기가 실패한 보상과 서버가 데이터 필드에 더한 보상이 함께 있을 때, 서버가 더한 값이 게임 안의 값에 빠지던 문제를 고쳤습니다. 빠진 채로 저장하면 서버가 더한 값이 덮여 사라졌습니다.

## 0.3.0 {#v0-3-0}

2026-11-20

::: warning 게임 코드를 고쳐야 합니다
`SupabaseSettings`의 `duplicateSessionPollSeconds`·`duplicateSessionActionCheckCooldownSeconds`를 지웠습니다. 게임 코드에서 이 값을 쓰고 있었다면 그 줄을 지우세요. 접속 확인은 60초로 고정되고, 중복 로그인 감지는 늘 켜져 있습니다.
:::

- **다른 기기 로그인 즉시 거절** — 다른 기기에서 같은 계정으로 로그인하면, 옛 기기의 다음 요청을 서버가 그 자리에서 거절합니다. 앱으로 돌아올 때도 바로 확인합니다. [중복 로그인 감지](/guide/auth/duplicate-login)를 참고하세요.
- **저장 중 접속 확인 생략** — 세이브 저장이 성공하면 접속 확인을 60초 미룹니다. 저장이 이어지는 동안에는 접속 확인 요청이 나가지 않습니다.
- **자동 로그인 중복 감지** — 다른 기기가 쓰고 있는 계정을 자동 로그인으로 되살리면 `SupabaseReason.DuplicateLogin` 실패로 알립니다.
- **우편 보상 서버 지급** — 우편 보상 키가 숫자 데이터 필드 이름과 같으면, 받을 때 서버가 그 필드에 더합니다. 처리기는 더하기만으로 안 되는 보상에만 등록하면 됩니다. [아이템 핸들러 등록](/guide/mailbox/item-handler)을 참고하세요.
- **세이브 변경 확인 메모리 절감** — 세이브 변경을 확인할 때 쓰는 메모리를 줄였습니다.
- **가이드 실사용 예시** — 가이드의 함수 페이지마다 실사용 예시를 넣었습니다.

## 0.2.1 {#v0-2-1}

2026-11-19

- **새 상태 값 안전하게 읽기** — 서버가 SDK보다 새 친구 관계·매치 로비 상태를 보내면 `Unknown`으로 읽습니다. 전에는 다른 상태로 잘못 읽었습니다.
- **차단 정보 함께 전달** — 차단된 계정이 구글·애플 연결을 누르면 실패 결과에 차단 기간과 사유가 함께 옵니다.
- **처리기 없는 우편 보상 실패** — 처리기가 등록되지 않은 우편 보상을 받으면 `SupabaseReason.MailItemHandlerMissing`으로 실패합니다.

## 0.1.2 {#v0-1-2}

- **리더보드 잘못된 점수 거절** — 리더보드에 숫자가 아닌 점수(NaN·무한대)를 보내면 서버에 묻기 전에 `SupabaseReason.LeaderboardScoreInvalid`로 실패합니다.

## 0.1.1 {#v0-1-1}

2026-11-12

- **매치 결과 보상 우편 중단** — 매치 결과는 고객 응대용 기록만 남기고 승리 보상 우편을 보내지 않습니다. 게임 코드는 고치지 않아도 됩니다.
- **안드로이드 애플 로그인 보안 강화** — 안드로이드 애플 로그인을 일회용 확인값 방식으로 바꿔, 다른 앱이 로그인 정보를 가로채지 못하게 했습니다.
- **판 골라 받기** — 설치 주소 끝에 판 번호를 붙여 원하는 판을 받을 수 있습니다.
