# 프로젝트 생성

게임 하나에 프로젝트 하나를 운영 콘솔에서 만듭니다. 데이터베이스와 서버 함수는 미리 준비돼 있어 따로 설치하지 않습니다.

## 1. 운영 콘솔 로그인

[트루베이스 운영 콘솔](https://truebase-admin.pages.dev)에서 초대받은 계정으로 로그인합니다. 구글 로그인과 이메일·비밀번호 로그인 중 하나를 씁니다.

로그인하면 들어갈 수 있는 프로젝트 목록이 나옵니다.

::: info 초대가 필요합니다
트루베이스에 초대된 계정만 로그인할 수 있습니다. 초대는 트루베이스 관리자에게 요청합니다.
:::

## 2. 새 프로젝트 만들기

1. 프로젝트 목록 아래 **새 프로젝트 만들기**를 누릅니다.
2. **프로젝트 이름**에 콘솔에 보일 이름을 넣고 **만들기**를 누릅니다. 이름은 40자까지 넣을 수 있고, 나중에 **설정 › 일반**에서 바꿀 수 있습니다.
3. 만든 프로젝트로 바로 들어갑니다. 만든 사람이 그 프로젝트의 첫 운영자가 됩니다.

::: warning 새 프로젝트 만들기가 보이지 않으면
만들 수 있는 프로젝트가 남아 있지 않은 것입니다. 트루베이스 관리자에게 요청합니다.
:::

다른 사람이 함께 운영하려면 **운영자 관리**에서 트루베이스에 초대된 사람을 골라 더합니다.

## 3. 연결 정보 확인 {#connection}

**설정 › 서비스 연결 › Supabase**의 **연결 정보**에서 값을 복사합니다. [초기 설정](/guide/start/init-setup)에서 씁니다.

| 항목 | 사용처 |
|------|--------|
| **Project URL** | `SupabaseSettings.projectUrl` |
| **Publishable Key** | `SupabaseSettings.publishableKey` |
| **생성기 열쇠** | 유저 데이터·원격 설정 클래스 생성기. **발급**을 누르면 나타납니다 |

::: info 생성기 열쇠
테이블 구조와 원격 설정을 읽는 데만 쓰입니다. 발급한 사람의 이름으로 1년 동안 유효하고, 그 사람을 운영자에서 빼면 바로 막힙니다. 누가 언제 발급했는지는 **운영 기록**에 남습니다.
:::
