# 닉네임

닉네임 설정·변경과 공개 프로필 조회 기능입니다. 닉네임은 서버에서 중복 여부를 검증하므로 전체 고유합니다.

내 닉네임은 `Supabase.MyProfile.DisplayName`으로 읽습니다 ([로그인 후 사용 가능한 값](/guide/auth/auto-login#after-login-values) 참고).

| 기능 | 메서드 |
|------|--------|
| 중복 확인 | [중복 확인](./check) |
| 닉네임 설정 | [닉네임 설정](./set) |
| 다른 플레이어 닉네임 조회 | [다른 플레이어 조회](./get-other) |
