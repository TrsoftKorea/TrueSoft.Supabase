# 세션 여러 개로 나눠 일하기

트루베이스 작업을 세션 여러 개가 동시에 나눠 맡는 방법입니다. 세션마다 맡은 곳이 정해져 있어서 서로의 파일을 덮어쓰지 않고, 끝난 쪽부터 따로 게시할 수 있습니다.

## 1. 세션 열기

앱에서 이 폴더(`D:\Project\TrueSoft.Supabase`)로 새 세션을 엽니다. 하는 일이 겹치지 않을 때만 여러 개를 엽니다. 보통은 둘이면 충분합니다.

| 세션 이름 | 맡는 일 | 첫 메시지 |
|---|---|---|
| 트루베이스 · 콘솔 | 운영 콘솔 화면, 콘솔 서버, 고객센터 창 | `역할 콘솔` 다음 줄에 할 일 |
| 트루베이스 · SDK | 게임이 받는 SDK 코드 | `역할 SDK` 다음 줄에 할 일 |
| 트루베이스 · 문서 | 가이드 문서만 | `역할 문서` 다음 줄에 할 일 |

첫 메시지 예:

```text
역할 콘솔
우편 내역 화면에 받는 사람 검색을 넣어 줘
```

`역할 …` 은 메시지 **맨 앞**에 써야 합니다. 그 세션이 "콘솔 역할을 맡았다"고 한 줄로 답하면 된 것입니다. 세션 이름은 구분하기 쉽게 붙이는 것이고, 역할을 정하는 것은 첫 메시지입니다.

## 2. 일하는 동안

- 데이터베이스 설치 파일, 가이드 문서, 검사 도구, 규칙 파일은 모든 세션이 함께 씁니다.
- 세션이 맡은 곳 밖의 파일을 고치려 하면 확인창이 뜹니다. 그 일이 정말 그 세션 몫이면 허용하고, 아니면 거절한 뒤 맞는 세션에 시킵니다.
- 다른 세션이 15분 안에 고친 파일을 고치려 해도 확인창이 뜹니다. 두 세션이 같은 파일을 동시에 고치면 게시 때 함께 올라가야 해서, 한쪽이 끝난 뒤 하는 편이 낫습니다.

## 3. 게시

세션이 일을 마치면 "게시를 눌러 주세요"라고 안내합니다. 미리보기의 **게시**를 누르면 세션별 묶음이 나옵니다.

- 끝난 세션의 묶음만 체크해서 올립니다. 체크하지 않은 묶음과 아직 묶음을 만들지 않은 작업은 그대로 남습니다.
- 빨간 글로 "다른 세션도 고친 파일"이 보이면, 거기 적힌 세션의 묶음도 함께 체크해야 올라갑니다. 그 세션이 아직 일하는 중이면 끝날 때까지 기다립니다.
- 그 세션을 이미 닫아 버렸다면 아무 세션에 `역할 해제 SDK` 처럼 보내면 풀립니다.

## 4. 끝낼 때

세션을 그냥 닫아도 됩니다. 같은 세션에서 역할 없이 계속하려면 `역할 해제` 라고 보냅니다.

## 안 되는 것

- 한 세션 안에서 띄운 보조 작업끼리는 구분하지 못합니다. 같은 세션이라서 그렇습니다.
- 세션이 명령줄로 직접 쓴 파일은 기록되지 않습니다. 평소 파일 고치기는 모두 기록됩니다.
- 지금 어느 세션이 어떤 역할인지 보려면: `node .claude/hooks/zone-claim.mjs --list`
