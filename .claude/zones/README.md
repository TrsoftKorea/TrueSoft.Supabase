# 세션 여러 개로 나눠 일하기

트루베이스 작업을 「트루베이스」 세션과 「콘솔 담당」 세션이 나눠 맡는 방법입니다. 일은 「트루베이스」 세션 하나에만 시키면 됩니다. 그 세션이 콘솔 일을 콘솔 담당에 넘기고, 확인이 필요한 것은 대신 여쭙고, 결과를 모아 알립니다.

## 1. 세션 열기

앱에서 이 폴더(`D:\Project\TrueSoft.Supabase`)로 세션을 엽니다. 처음 한 번만 하면 됩니다.

| 세션 이름 | 맡는 일 | 첫 메시지 |
|---|---|---|
| 트루베이스 | 이야기 상대 · 일 나누기 · 게시 안내 | 평소처럼 할 일 |
| 콘솔 담당 | 운영 콘솔 화면, 콘솔 서버, 고객센터 창 | `역할 콘솔` |

SDK·데이터베이스·문서는 「트루베이스」 세션이 직접 고칩니다.

「트루베이스」 세션의 이름은 꼭 이대로 둡니다 — 콘솔 담당이 이 이름으로 찾아옵니다. **역할은 「트루베이스」 세션이 떠 있을 때만 정합니다.** 역할을 정한 세션은 직접 묻지 못하고 확인도 「트루베이스」를 거치므로, 「트루베이스」 없이 혼자 쓰면 일이 멈춥니다 — 그때는 `역할 해제` 라고 보냅니다. 담당 세션은 첫 메시지로 역할만 정해 두면, 그 뒤로는 창을 열어 볼 필요가 없습니다. `콘솔 담당이야`처럼 역할 이름 뒤에 "담당"을 붙여 시작해도 됩니다. 그 세션이 역할을 맡았다고 한 줄로 답하면 된 것입니다.

## 2. 일 시키기

「트루베이스」 세션에 평소처럼 말합니다. 그 세션이 콘솔 일을 콘솔 담당에 보내고, 그 밖과 몇 줄짜리 일은 직접 합니다.

- 콘솔 담당이 콘솔 밖을 고쳐야 하거나 무언가 물어야 하면, 「트루베이스」 세션이 대신 여쭙습니다. 허락하시면 그 파일만 30분 동안 열립니다.
- 데이터베이스 설치 파일, 가이드 문서, 검사 도구, 규칙 파일은 모든 세션이 함께 씁니다.

## 3. 게시

「트루베이스」 세션이 콘솔 담당의 결과까지 확인한 뒤 "게시를 눌러 주세요"라고 한 번에 안내합니다. 미리보기의 **게시**를 누르면 세션별 묶음이 나옵니다.

- 끝난 세션의 묶음만 체크해서 올립니다. 체크하지 않은 묶음과 아직 묶음을 만들지 않은 작업은 그대로 남습니다.
- 빨간 글로 "다른 세션도 고친 파일"이 보이면, 거기 적힌 세션의 묶음도 함께 체크해야 올라갑니다.
- 노란 상자로 "넣은 내용이 사라졌습니다"가 보이면, 한 세션이 넣은 내용을 다른 세션이 지운 것일 수 있습니다. 확인하고 체크해야 올라갑니다.
- 담당 세션을 이미 닫아 버려 묶음이 막혔다면 「트루베이스」 세션에 `역할 해제 콘솔` 처럼 보내면 풀립니다.

## 4. 끝낼 때

세션을 그냥 닫아도 됩니다. 같은 세션에서 역할 없이 계속하려면 `역할 해제` 라고 보냅니다.

## 안 되는 것

- 한 세션 안에서 띄운 보조 작업끼리는 구분하지 못합니다. 같은 세션이라서 그렇습니다.
- 세션이 명령줄로 직접 쓴 파일은 기록되지 않습니다. 평소 파일 고치기는 모두 기록됩니다.
- 지금 어느 세션이 어떤 역할인지 보려면: `node "$HOME/.claude/scripts/zone.mjs" list`
